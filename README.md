# AI Voice Assistant for Uzhavan App

## Overview
An AI-powered voice assistant that helps farmers navigate the Uzhavan app using voice commands.

## Features
- Voice-based navigation
- Tamil language support
- Gemini API integration
- Direct access to government services

## Tech Stack
- HTML
- CSS
- JavaScript
- Python (Flask)
- Gemini API

## Architecture
Farmer → Uzhavan App → Speech-to-Text → Gemini API → Navigation Engine → Uzhavan Services
